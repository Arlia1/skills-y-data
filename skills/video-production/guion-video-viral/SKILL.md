# Guion de Video Viral

## 0. Regla de oro

**Una idea por video.** Si el brief tiene dos ideas, son dos videos.
No empieces por la animación ni por el código: primero el guion, después el estilo, después la producción.

Orden obligatorio:

1. **Brief** — tema, audiencia, plataforma, duración, idioma, CTA, voz sí/no.
2. **Premisa + logline** — una frase con deseo, obstáculo y promesa.
3. **Estructura** — elige UN modelo y dibuja los beats.
4. **Beat sheet** — tiempos, acción visual, giro, cámara, audio.
5. **Guion** — literario (Fountain) o técnico (shot list).
6. **Validación** — hook, claridad, escalada, loop, duración.

## 1. Premisa y logline

Antes de escribir beats, clava estas cinco líneas:

| Campo | Pregunta |
|---|---|
| Protagonista | ¿Quién? (puede ser un objeto, una marca, el espectador) |
| Deseo | ¿Qué quiere, visible en pantalla? |
| Obstáculo | ¿Qué se lo impide y por qué ahora? |
| Giro | ¿Qué cambia a mitad? |
| Promesa | ¿Qué se lleva el espectador al final? |

Logline: `[Protagonista] quiere [deseo] pero [obstáculo]; cuando [giro], debe [decisión] o [consecuencia].`
Si no cabe en una frase, la historia todavía no existe.

## 2. Estructura por duración

### 15 segundos
| t | Beat | Función |
|---|---|---|
| 0–2 s | Hook | Conflicto, amenaza, pregunta o imagen imposible. Cero contexto. |
| 2–6 s | Setup | Una sola pieza de información, visual. |
| 6–12 s | Escalada | El obstáculo crece o se revela el patrón. |
| 12–15 s | Payoff + loop | Resolución visual y última imagen que enlaza con el hook. |

### 30 segundos (formato principal)
| t | Beat | Función |
|---|---|---|
| 0–2 s | Hook | El primer frame ya está en conflicto. |
| 2–6 s | Anclaje | Primer valor concreto; el espectador entiende de qué va. |
| 6–20 s | Escalada | 3–4 beats; cada uno sube apuesta, revela o invierte poder. |
| 20–26 s | Giro | Lo que parecía X era Y; el deseo cambia de precio. |
| 26–30 s | Payoff + loop | Cierre visual; la última frase o imagen conecta con 0 s. |

### 45–60 segundos
Cuatro actos: **Hook (0–3) → Contexto (3–10) → Núcleo (10–45; cambio perceptible cada 4.5 s) → Loop (45–60)**.
Si hay voz: 80–115 palabras (2.5–2.8 palabras/s). Sin despedidas ni "suscríbete" en el cierre.

## 3. Modelos narrativos

- **Problema → Agitación → Solución** (ads, producto, servicio).
- **Antes → Después** (transformación; el "antes" debe doler en 2 s).
- **Tres actos comprimidos**: setup (25%), confrontación (50%), resolución (25%).
- **Kishōtenketsu** (sin conflicto): introducción → desarrollo → giro → síntesis. Ideal para papercut, lowpoly y videos contemplativos.
- **Save the Cat simplificado**: imagen de apertura → promesa → giro central → todo se pierde → imagen final espejo.
- **Short-drama**: hook duro → presión creciente → revelación → cliffhanger o loop.

Para profundidad usa `cinematic-story-architecture` (beats), `short-drama-hook-engineering` (hook/retención) y `sw-story-structure` (Field, Snyder, McKee, kishōtenketsu).

## 4. Beat sheet

Cada fila debe poder rodarse/renderizarse sin preguntas. Si un beat solo dice "se siente triste", no es un beat.

| t | Beat | Acción visual | Giro emocional | Cámara | Audio / voz | Texto |
|---|---|---|---|---|---|---|
| 0–2 | Hook | … | … | … | … | … |
| 2–6 | Anclaje | … | … | … | … | … |
| … | … | … | … | … | … | … |

Reglas:
- **Hook:** empieza lo más tarde posible dentro de la acción; prohibido logo, intro, saludo o plano bonito neutro.
- **Cada beat:** o sube la apuesta, o revela información, o invierte el poder. Si no hace ninguna, se corta.
- **Cada 2–4.5 s:** cambio de plano, escala, geometría o sonido. Un plano largo solo se queda si aumenta la presión.
- **Cierre:** última frase gramaticalmente incompleta o imagen que conecta con el primer frame.
- **Show, don't tell:** cada idea abstracta se convierte en un objeto, gesto o acción visible.
- **Diálogo:** cada línea ataca, defiende, revela, oculta o rompe. Nada de exponer contexto.

## 5. Formatos de entrega

### Guion literario (Fountain)
```
INT. TALLER DE PAPEL - NOCHE

Una TIJERA entra en cuadro y corta el silencio.

NIÑA
(para sí)
Si lo corto bien, la luz entra.

La sombra de la tijera se convierte en un animal.
```
Escenas con `INT./EXT.`, acción en presente, personajes en MAYÚSCULAS, diálogo bajo el personaje.
Detalle en la skill `screenplay-fountain-format`.

## 6. Validación antes de producir

```
[ ] El hook se entiende sin audio y sin contexto.
[ ] Una sola idea; se puede resumir en una frase.
[ ] El primer valor aparece antes del segundo 8.
[ ] Hay un cambio perceptible cada ~4.5 s (o presión creciente equivalente).
[ ] Cada beat tiene acción visual filmable/renderizable.
[ ] El giro cambia el significado de lo anterior.
[ ] El cierre enlaza con el inicio (loop) o deja una pregunta concreta.
[ ] Duración real: guion leído en voz alta ≤ duración objetivo.
[ ] Texto en pantalla dentro de la zona segura 9:16.
[ ] Sin clichés: "en un mundo donde", "no es solo X, es Y", "¿estás listo?".
```
