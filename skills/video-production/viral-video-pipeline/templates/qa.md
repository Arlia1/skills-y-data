# QA — puertas del pipeline

Versión:

## G0 — Brief
- [ ] Audiencia concreta
- [ ] Promesa en una frase
- [ ] CTA definido
- [ ] Plataforma y duración

## G1 — Research
- [ ] 3–5 referencias analizadas
- [ ] Patrones extraídos (hook, ritmo, audio, CTA)
- [ ] Gap o ángulo propio identificado
- [ ] Nada copiado

## G2 — Idea
- [ ] Una sola idea
- [ ] 3 hooks escritos
- [ ] Hook elegido pasa checklist de 8 puntos
- [ ] Test de shareability

## G3 — Guion
- [ ] Logline en una frase
- [ ] Beat sheet con tiempos
- [ ] Cada beat tiene acción visual y giro
- [ ] Cronometrado en voz alta
- [ ] Loop o cierre conectado

## G4 — Estilo
- [ ] Un solo estilo
- [ ] Tratamiento escrito
- [ ] Paleta 3–5 colores + neutros
- [ ] Tipografía definida
- [ ] Qué NO va a tener

## G5 — Preproducción
- [ ] Shot list
- [ ] Scene cards
- [ ] Cue sheet de audio
- [ ] Assets y fuentes
- [ ] Licencias
- [ ] Calendario

## G6 — Producción
- [ ] Stills en beats clave
- [ ] Aprobados a 1080×1920
- [ ] Grounding / colisiones
- [ ] Texto dentro de contenedores
- [ ] Paleta consistente

## G7 — Post
- [ ] Mobile test
- [ ] Mute test
- [ ] Squint test
- [ ] Grayscale test
- [ ] Loop verificado
- [ ] Audio −14 LUFS / −1 dBTP
- [ ] Export reproducible

## Publicación
- [ ] Caption + hashtags
- [ ] Portada
- [ ] Horario
- [ ] Cross-post adaptado

## Análisis
- [ ] 24 h: retención 3 s, media, guardados, compartidos
- [ ] 7 días: follows, CTR, comentarios
- [ ] Decisión: iterar / repetir formato / descartar
