# Research — patrones, no copias

## Referencias y qué extraemos

1. **Aubrium — Best hooks for web design reels (2026)**
   https://aubrium.com/blog/best-hooks-for-web-design-reels
   - 500+ reels analizados: 77% ponen el hook como texto en pantalla.
   - El hook medio tiene 9 palabras; los de 5–12 palabras viajan más.
   - Los hooks "relatable" rinden 36×; POV 24×; transformation tease 12×.
   - Patrón: texto en pantalla + voz, no solo voz.

2. **Dobidy — Transformation Videos Are Dominating Social Media in 2026**
   https://dobidy.com/blog/transformation-video-trends-2026
   - El antes/después es el formato de mayor crecimiento.
   - Funcionan reveals de 5–15 s; `#BeforeAndAfter` supera 87B de views.
   - Patrón: tensión visual → transformación → payoff claro.

3. **Shortgen — 8 TikTok Slideshow Ideas for a Web Design Agency**
   https://shortgen.io/tiktok-slideshow-ideas/web-design-agency
   - Hooks que funcionan: "pov: you finally get a website that doesn't look like 2005", "before and after: same client, new site", "stop paying $5k for a Wix template".
   - Patrón: situación reconocible + promesa concreta + lenguaje sin corporate.

4. **Viral Hooks — Explaining a website redesign process**
   https://viralhooks.org/database/5384-explaining-a-website-redesign-process/
   - Estructura: resultado dramático → autopsia del "antes" → estrategia del "después" → principio universal.
   - Patrón: mostrar el proceso, no solo afirmar el resultado.

5. **Virlo — Lovable TikTok Playbook**
   https://signal.virlo.ai/p/lovable-tiktok-playbook-one-format-steal-it
   - Formato: encontrar un negocio real → construir la web → mostrar el resultado → cerrar con una acción y un número creíble.
   - Patrón: el proceso visible genera confianza; el número pequeño y concreto baja la objeción.

## Datos de contexto (usar con pinzas)
- **Clutch (2025):** 83% de pymes de EE.UU. tiene web; 17% no. https://clutch.co/press-releases/smb-websites-2025
- **NFIB (2025):** 82% tiene web; en negocios de 1–9 empleados, 75%. https://www.nfib.com/news/analysis/nfib-survey-sheds-light-on-new-technologies-for-small-business/
- **HostingAdvice (2025):** 66% de encuestados evita negocios con webs viejas o mal diseñadas. https://www.hostingadvice.com/studies/ugly-websites-survey/

No usar estos números como si fueran de Argentina. En el video, la verdad es observable: "tu cliente busca en Google; si no estás, le compra a otro."

## Gap
La mayoría de los reels de diseño web son screen recordings, talking heads o slideshows. Un **papercut narrativo** con una metáfora clara ("tu negocio es una hoja en blanco") es distinto, brandable y muestra la transformación sin depender de un caso real.

## Decisión
- Hook relatable + metáfora visual.
- Antes/después con transformación papercut.
- Una sola promesa: visibilidad + clientes.
- CTA único: DM `PRESUPUESTO`.
